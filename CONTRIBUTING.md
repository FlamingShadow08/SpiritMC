# Contributing to Spirit

Spirit is in early development, and its architecture and contribution process are still taking shape.

## Before contributing

- Check existing issues and discussions before starting substantial work.
- For significant changes, open an issue first to discuss the proposed scope and direction.
- Keep changes focused and document important design or architectural decisions.

## Pull requests

When submitting a pull request:

- Explain what changed and why.
- Include relevant screenshots or recordings for user-interface changes.
- Include test results when applicable.
- Avoid bundling unrelated changes.

More detailed development and review guidelines will be added as the project matures.
