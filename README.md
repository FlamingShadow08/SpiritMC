# Spirit

Spirit is an evolving Minecraft software ecosystem, bringing together its launcher, client, and supporting tools under one project.

This repository is organized as a **monorepo**. Each application remains an independent project, while shared documentation and repository-level configuration live at the root.

## Repository structure

```text
SpiritMC/
├── apps/
│   ├── launcher/   # Spirit Launcher
│   └── client/     # Spirit Client
├── docs/           # Project-wide documentation
├── .github/        # GitHub configuration and community health files
├── .gitignore
├── CONTRIBUTING.md
├── LICENSE.md
└── README.md
```

## Project status

Spirit is in early development. Its architecture, tooling, and repository structure may evolve as the project takes shape.

- **Launcher:** Initial development workspace.
- **Client:** Reserved for future development.
- **Documentation:** Project-wide architecture, technical decisions, and development documentation.
